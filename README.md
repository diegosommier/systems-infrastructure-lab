# Systems Infrastructure Lab

A hands-on systems administration and infrastructure project developed between November 2017 and April 2018 as part of a Systems Administration course.

The project uses virtual machines and classroom infrastructure to build and configure a mixed Linux and Windows environment, covering server administration, networking, security, services, monitoring, inventory and automation.

## Project scope

### Linux

The main part of the project focuses on Linux system administration and service configuration, including:

* Initial system configuration and administration
* SSH installation and security hardening
* WordPress installation and configuration
* phpMyAdmin installation and configuration
* Logwatch configuration for log analysis
* Samba configuration and file sharing
* rsnapshot configuration for backups
* Samba automation through scripting
* Pandora FMS monitoring agent
* OCS Inventory agent

### Windows

The project also includes the configuration and administration of Windows systems:

* Windows 10
* Pandora FMS monitoring agent
* OCS Inventory agent
* Windows Server 2012

## Project context

This project was developed between **November 2017 and April 2018** as the final project for a Systems Administration course at Dicampus.

It was created to demonstrate the practical knowledge acquired throughout the course by configuring a combination of physical classroom infrastructure and virtual machines.

The project is preserved in its original form as part of my technical portfolio, providing a reference point for my early work in systems administration and infrastructure.

## From Systems to Cloud

This project represents an earlier stage of my infrastructure journey.

The experience gained working with operating systems, services, networking, security, monitoring, backups and automation provides the foundation for my current focus on **Cloud, automation and DevOps**.
